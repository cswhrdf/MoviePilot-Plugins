# 共享识别词(个人版)

从 Github、Etherpad 等远程文件中拉取共享识别词，合并进系统的自定义识别词并周期刷新，避免每次手动复制粘贴词表。

---

## 能力

- 支持两类远程源：纯文本词表（一行一个识别词）与 JSON 订阅集合（`词表名 -> 词表地址` 的对象）。
- Etherpad 地址自动补 `/export/txt`，直接填页面地址即可。
- 定时任务按 `cron` 周期拉取，也可用「立即运行一次」手动触发。
- 写入时先截断上一轮由本插件写入的词条（含标记行 `RemoteIdentifiers`），再追加本轮结果，用户自己维护的词条不受影响。
- 「过滤空白行」开启时丢弃空行，避免空词条进入识别词列表。
- 请求失败会重试（最多 3 次，退避递增），下载到 HTML 页面或限流提示会显式报错而不是写入脏数据。

---

## 配置项

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 启用插件 | `false` | 开启后插件状态为启用，定时任务才会注册 |
| 过滤空白行 | `true` | 丢弃词表中的空行 |
| 立即运行一次 | `false` | 保存后 3 秒执行一次拉取，随后自动关闭 |
| 定时任务周期 | `30 4 * * *` | 五段 cron 表达式 |
| 远程文件地址 | 两个 Putarku 词表 | 一行一个，纯文本词表或 JSON 订阅文件 |
| 免代理地址 | 空 | 一行一条，命中即直连，未命中仍走全局代理 |

---

## 免代理配置（`no_proxy_hosts`）

默认情况下，插件的远程请求沿用宿主的全局代理 `PROXY`。如果词表放在内网或本机，走代理会失败，此时在「免代理地址」里填上目标主机即可直连。

- 一行一条，支持四种写法：

  | 写法 | 示例 | 匹配方式 |
  | --- | --- | --- |
  | 域名 | `raw.githubusercontent.com` | 完全相等，不匹配子域名 |
  | IP | `127.0.0.1`、`::1` | 地址相等 |
  | CIDR | `192.168.0.0/16`、`fd00::/8` | 地址落在网段内 |
  | 通配 | `*.internal.lan`、`nas-?` | 逐字符通配（`*` 可跨点） |

- 只写主机，不要带协议、端口或路径：`https://nas.lan:8443/words.txt` 应写成 `nas.lan`；带这些内容的那一行会被跳过。
- 非法行会被忽略：该行不生效、其余行照常生效，同时在配置页「免代理地址」上方以告警形式回显「第 N 行原因（原文）」，日志中也会记录一条跳过提示。
- 地址解析不出主机名时回退全局代理，并记录一条告警日志。
- 规则在插件初始化与保存配置时重新解析，改完配置保存即生效。

### 示例

```text
127.0.0.1
::1
192.168.0.0/16
*.internal.lan
```

配合这样的「远程文件地址」即可让内网词表直连、公网词表继续走代理：

```text
http://nas.internal.lan:5000/words/tv.txt
https://raw.githubusercontent.com/Putarku/MoviePilot-Help/main/Words/TV.txt
```

---

## 注意事项

- 本插件写入的是系统的自定义识别词列表，会覆盖上一轮由本插件追加的段落；如需保留自己的词条，请在标记行之前维护。
- 远程词表内容由第三方维护，来源可靠性与更新频率需自行判断。
- 词表体积很大时，识别词条数会同步增长，请留意宿主识别性能。
